# set up your server in my perferred fashion with just a copy and paste!
copy the commands below to get started

## basic install

```
git clone https://github.com/PAN-DA-BOI/server-set-up.git
chmod +x ./ServerSetup.sh
./ServerSetup.sh
```

## install with gthub files
this is just an example, but you can add a flag of a github link to have your files all ready to go when its done rebooting!

```
git clone https://github.com/PAN-DA-BOI/server-set-up.git
chmod +x ./ServerSetup.sh
./ServerSetup.sh https://github.com/PAN-DA-BOI/map.git
```
